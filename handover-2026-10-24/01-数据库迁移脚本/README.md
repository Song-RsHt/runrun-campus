# 数据库迁移脚本说明

- 数据库：PostgreSQL。
- 迁移工具：Flyway，由 Spring Boot 启动时按版本顺序执行。
- 当前资料：V1–V43，共 43 个 SQL 文件，编号连续且无重复。
- V1 是基础结构；后续脚本按 V2、V3……V43 的顺序增量修改。
- 生产服务器当前运行 JAR只包含到 V41；V42、V43 属于当前本地源码中的后续改动，尚未证明已经应用到生产库。

协作者必须遵守：

1. 先在全新空数据库验证 V1–V43 能完整执行。
2. 再用生产数据库的脱敏结构备份验证从现有版本升级到最新版本。
3. 不得修改已经存在的 V1–V43 文件；新增结构从 V44 开始。
4. 禁止把生产数据库导出文件、真实用户数据或数据库密码放入源码包。
5. 正式迁移前必须完成备份、恢复演练和回滚方案，并由项目所有者确认维护窗口。

本目录是为了便于单独审查而复制的清单；后端实际加载位置仍为：

`RunRunCampusBackend/src/main/resources/db/migration`
