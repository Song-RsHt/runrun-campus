# 隔离测试环境接入清单

子域名待甲方提供。收到后按以下顺序验证，不连接生产服务：

1. DNS 解析到测试服务器，HTTPS 证书与域名匹配。
2. `GET https://<TEST_SUBDOMAIN>/api/v2/service-config` 和 `/api/v2/privacy/policy` 返回 v2 服务响应（未登录返回 401 或业务错误均可，不能 404）。
3. 微信公众平台的 `request`、`uploadFile` 合法域名包含该子域名。
4. 微信开发者工具存储键：
   - `rrc_api_environment`: `test`
   - `rrc_api_base_url`: `https://<TEST_SUBDOMAIN>`
   - `rrc_api_allowed_hosts`: `["<TEST_SUBDOMAIN>"]`
   - `rrc_mock_payment_enabled`: `true`
5. 使用 `scripts/build-miniapp.ps1` 生成测试构建元数据，再执行 CLI `preview`。

测试数据库、对象存储、AppSecret 和模拟支付必须与生产隔离。不要把真实密钥写入仓库或聊天。
