# 跑跑代取微信小程序项目交接说明

交接基线日期：2026-10-22

## 1. 项目定位

本项目是复用现有跑跑校园后端的微信原生小程序首版，产品名称为“跑跑代取”，覆盖普通用户与骑手两类账号的主要履约流程。

- 技术栈：微信原生小程序 JavaScript + WXML + WXSS
- 小程序源码目录：`RunRunCampusMiniProgram`
- 后端地址：`https://api.runruncampus.cn`
- 当前 AppID：`wx2971243a0c47d9cc`
- 正式产品名称：`跑跑代取`
- 支付时机：用户选择商品或包裹规格，确认后立即微信支付；后端确认到账后订单才进入骑手可接单池

小程序代码标题已统一为“跑跑代取”。正式提交前仍需同步微信公众平台资料和后端返回的隐私政策；当前生产隐私政策标题仍为“跑跑校园隐私政策”，不能带着名称冲突提交审核。

## 4. 本地导入与运行

1. 安装微信开发者工具稳定版。
2. 用被加入该小程序项目成员的微信扫码登录。
3. 确认当前开发者已被管理员加入 AppID `wx2971243a0c47d9cc` 对应的小程序项目。
4. 在开发者工具中导入 `RunRunCampusMiniProgram` 目录，项目类型选择“小程序”。
5. 本地联调时可临时关闭合法域名校验；提交前必须重新启用并通过校验。
6. 在微信公众平台把 `https://api.runruncampus.cn` 配置为 `request` 和 `uploadFile` 合法域名。
7. 编译后分别用用户账号和骑手账号检查页面与接口。

不要把 AppSecret、管理员密码、短信验证码、数据库口令、对象存储密钥或代码上传私钥放入本项目。AppSecret只能保存在可信后端。

## 5. 账号与权限交接

项目所有者应通过微信公众平台把合作者添加为项目成员或开发者，不要共享管理员微信账号和密码。建议分别交接：

- 小程序 AppID；AppID是标识符，不是密钥
- 微信公众平台开发者权限
- 私有代码仓库权限
- 后端测试环境地址及测试账号
- 必需的运营后台测试权限

生产密钥应通过密码管理器或其他受控渠道单独交接，不应放入聊天、源码、压缩包或普通文档。

## 8. 责任边界

小程序只负责客户端交互。订单权限、价格计算、角色授权、状态机、支付确认、收货码校验和文件访问控制必须以后端为准，不能只依赖页面按钮是否显示。

正式目标流程为：用户选择规格 → 后端计算并返回应付金额 → 用户确认订单 → 微信支付 → 后端确认到账 → 订单进入骑手可接单池 → 骑手接单并履约。未支付、支付中或支付结果未知的订单不得出现在骑手可接单列表。实际规格不符时，由后端发起补差价或部分退款流程，不能由骑手线下改价，也不能直接覆盖原支付记录。

个人收款码、骑手学生证照片、手机号、位置、订单凭证和付款核对备注都涉及敏感信息。继续开发和发布前，需要由运营主体确认收集目的、保存期限、访问权限、用户告知及删除机制。
