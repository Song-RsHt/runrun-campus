## 管理端端口和精确 CORS

本轮使用的可用端口为 **5186**；甲方机器必须先检查，不能假设仍空闲：

```powershell
$AdminPort = 5186
if (Get-NetTCPConnection -State Listen -LocalPort $AdminPort -ErrorAction SilentlyContinue) {
    throw '所选管理端端口已占用，请另选空闲端口，并同步配置 Origin'
}
```

在原 `.env.v2-test` 中**仅新增或更新这一项**，其他密码/密钥保持原值：

```dotenv
RRC_LOCAL_ADMIN_ORIGIN=http://127.0.0.1:5186
```

若选其他端口，以下预览端口和 CORS Origin 必须同步。默认 dev/preview 都仍为 5173，且启用 strictPort；占用时报错退出 1，不会静默换端口。默认 CORS 现仅允许 `http://127.0.0.1:5173`；使用 localhost 必须显式配置 `http://localhost:<端口>` 并以该地址访问，不再同时默认允许两个主机名。不要停止无关 Docker 项目，不用 IPv6 绕行，不配置 `*`。端口参数只决定前端监听地址，不会自动改后端 CORS。

| 骑手资质 | GET `/api/v2/courier/certification/admin` 200；默认列表、PENDING筛选及搜索可用，空数据正确显示空态 |
