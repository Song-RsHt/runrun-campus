# 骑手资质与学生证证据权限矩阵

| 操作 | 骑手本人 | 已启用管理员 | 其他身份 |
|---|---|---|---|
| 查看本人资质状态 | 允许 | 允许（列表/详情） | 拒绝/404 |
| 首次申请、重新申请 | 允许；`PENDING` 期间拒绝重复申请 | 不代替骑手申请 | 拒绝 |
| 上传学生证 | 仅本人当前 `PENDING` 申请；JPEG/PNG；≤8 MiB | 不上传 | 拒绝 |
| 审核通过/驳回 | 拒绝 | 允许；锁、版本、申请轮次和照片资源同时校验 | 拒绝 |
| 读取学生证 | 拒绝 | 允许；短期受控响应、`Cache-Control: no-store`、访问审计 | 拒绝 |
| 建立/解除证据保全 | 拒绝 | 允许；与资质锁串行化 | 拒绝 |
| 到期删除/失败重试 | 拒绝 | 仅系统任务执行；失败保留引用并审计重试 | 拒绝 |

接单资格与照片生命周期分离：批准后删除照片不会撤销 `eligible`。保全期间禁止删除；删除前再次检查保全并标记 `DELETING`，对象存储成功后才清理引用。

并发规则：申请、重新申请、换图、审核共用资质行锁和 `version`。审核请求必须带读取时的版本和本次照片资源标识；冲突返回 `CERTIFICATION_STATE_CONFLICT`。照片替换先登记待删资源，不能覆盖后续上传的资源。
