# RunRunCampus 阶段一总控开发方案

版本：2026-10-27（M00 已独立验收；证据见 docs/reports/M00-acceptance.md）

## 1. 冻结的范围与裁决顺序

阶段一是全新微信小程序系统：独立空数据库、全新初始化迁移、`/api/v2`。不导入旧用户、骑手、订单、支付、资质或 API；不做旧账号恢复、v1/v2 合并、旧订单收尾或生产迁移。现有 `handover-2026-10-24`、V1–V43 迁移脚本和旧客户端只作只读代码参考。

规则冲突按以下顺序裁决：用户最新书面确认和《决策记录》→《阶段一业务基线》→专题规则与《数据模型与接口契约》（字段、接口、错误码以契约为唯一技术来源）→其他旧资料。无法裁决时暂停相关模块并记录影响。

支付、管理员付款登记和测试身份只能在隔离本地/测试/预发布启用；生产必须拒绝模拟入口。不得提交密钥、Token、密码、完整 openid、真实用户数据、上传文件、缓存、备份或生产制品。

## 2. 总体技术方案与依赖

```text
M00 契约/空库方案
          ↓
M01 身份、微信绑定、骑手、管理员启用
          ↓
M02 区域、服务点、营业时间、配置、报价、订单
       ↙       ↘
M03 模拟支付/退款/幂等      M04 骑手任务/容量/定位/履约
       \       /
        M05 规格调整/补款/降档退款/售后
                  ↓
        M06 分账/冻结/补贴/交接/模拟付款登记
                  ↓
        M07 资质/凭证/保全删除/通知
                  ↓
        M08 管理端、微信小程序与端到端验收
```

公共约束：数据库 snake_case、API camelCase、金额整数 cents、时间 TIMESTAMPTZ、ID 以字符串返回、坐标 GCJ02；聚合 `version` 与固定 `order_flow_version=2` 分离；写请求使用幂等键，更新使用 `expectedVersion`；副作用、审计、事件和 outbox 在同一事务；旧 V1–V43 不得被新迁移引用。

新系统后端根目录为 `server/`；独立迁移根目录为 `server/db/migrations/`，正向脚本与回滚脚本分目录管理，首版编号 `rrc_0001`。当前执行器为显式 `psql -X --set ON_ERROR_STOP=1 --file <精确文件>`；接入应用 runner 前须另验收版本历史、校验和与扫描范围，不能自动加载旧 Flyway 目录。每个迁移号和对象由 M00 登记，后续模块不得重复建表、重复索引或修改已执行迁移。

上图是业务集成顺序。M07 的共享证据基础设施必须前置并行：M01 的照片上传/审核、M04 的证据能力在生命周期服务联调验收前不得开放。前序可先交付独立基础对象，不能把完整证据安全要求延后到最后。跨模块后置外键和开启条件统一见 `docs/reports/M00-migration-registry.md`。

## 4. 模块交付与合并门禁

实现 agent 完成后必须提交交接单：修改文件清单、数据库对象（表/列/约束/索引/触发器）清单、API/错误码/权限清单、已实现与未实现、已运行/未运行验证、已知风险、安全边界、commit hash、是否建议合并。QA agent 仅只读检查 diff、迁移、测试和文档，不得替实现 agent 修代码；QA 结论为 `PASS`、`PASS_WITH_RISK` 或 `BLOCKED`，附证据路径。

总控合并顺序：先核对依赖和迁移登记 → 运行模块测试 → 运行只读 QA → 检查未夹带密钥/真实数据/缓存 → 记录状态表 → 仅当前提交取得独立 QA 的 `PASS` 并通过总控检查后才 cherry-pick 到 `main`；`PASS_WITH_RISK` 须先补齐本模块必需验证并重新验收，不能用风险记录替代完成标准。未验收分支不得合并；任何冲突先暂停模块并写入决策记录。

## 5. M00 和后续启动边界

1. M00 的迁移链、对象归属、公共接口引用和隔离容器验证由新报告登记；验收以当前提交与实际执行结果为准。
2. 建立模块登记表，锁定每个迁移号和数据库对象归属。
3. M01 尚未启动；后续须先建立新后端执行骨架及幂等、审计、outbox 等前序必需基础设施，再实现身份业务。M02 仅在 M01 API/表契约冻结后开始。
4. 总控创建 QA-0 只读验收任务，验收通过前不合并 M00。

本文件不是业务源码或真机验收证据；M00 只实现初始化基础，不包含 M01–M08 功能。
